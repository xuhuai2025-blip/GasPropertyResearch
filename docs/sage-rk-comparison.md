# RK 与 Sage 手册的对应关系

依据用户提供的 `D:/VibeCodingWorkSpace/SageStlxHyperlinked(1).pdf`，第 18.1 节和第 28.4 节。下述 PDF 页码为从 1 开始的文件页码；印刷页码比文件页码小 4。

## 1. 压力与热力学表达式

原实现与 Sage 的 RK 压力表达式相同：

`p = R*T/(v-b) - a/(sqrt(T)*v*(v+b))`，`v = 1/rho`。

`a = c1*R^2*Tc^2.5/Pc`，`b = c2*R*Tc/Pc`。

依据：PDF 148–149 / 印刷 144–145 页，式 (18.11)–(18.13)。内能为

`u = Cv0*T - 3*a/(2*b*sqrt(T))*log(1+b*rho)`。

依据：PDF 148、151 / 印刷 144、147 页，式 (18.10)、(18.26)。当前 `state` 的 `Cv`、`Cp`、声速均由同一压力与内能表达式的导数计算，保留热力学一致性；熵使用 PDF 153 / 印刷 149 页式 (18.34)。绝对内能和熵的参考零点不保证与 REFPROP 相同，比较时应比较状态差或明确对齐参考态。

密度采用 PDF 150–151 / 印刷 146–147 页式 (18.18)–(18.24) 的三次压缩因子方程，求最大实根，再用两步压力 Newton 修正消除浮点舍入误差。只计算压力及其导数，求根中不构造完整物性状态。

## 2. 真正不同的是拟合系数

原实现对所有纯气体使用标准 RK 的 `c1=0.4274802335403414`、`c2=0.08664034996495772`，并拒绝 Air。Sage 手册明确说明其默认数据库对第二维里系数拟合，因此并不使用统一的标准系数（PDF 149、326–328 / 印刷 145、322–324 页）。本实现采用手册公布值：

| 工质 | c1 | c2 | 来源 |
|---|---:|---:|---|
| He | 0.5338 | 0.05886 | PDF 327 / 印刷 323 页 |
| H2 | 0.4442 | 0.08207 | PDF 328 / 印刷 324 页 |
| N2 | 0.4456 | 0.1102 | PDF 328 / 印刷 324 页 |
| Air | 0.4372 | 0.1063 | PDF 328 / 印刷 324 页 |
| Ar | 0.4274802335403414 | 0.08664034996495772 | 标准 RK；手册未给出 Ar 拟合值 |
| CO₂ | 0.4274802335403414 | 0.08664034996495772 | 标准 RK；未提供 CO₂ 的 Sage 拟合值 |

Sage 的 Air 系数由 N2/O2 的体积分数加权得到。本包将 Air 当作固定组成的伪纯工质处理，不提供任意组分的混合规则。参考物性可以取用户 REFPROP 的 `AIR.PPF`，其中还包含 Ar；这与手册未提供完整组成的数据源并非逐项完全相同。

临界参数优先使用导出的 REFPROP 参考数据；未提供时保留原实现的纯工质临界参数，Air 使用用户 `AIR.PPF` 文件头的伪纯临界参数。气体常数统一使用所选 `GasProperties.R`，参考数据中的 `GasConstant` 必须与其一致（相对容差 `1e-10`），防止公开 `gas.R` 与状态返回的 `state.R` 不同。REFPROP 原有气体常数保存在来源元数据中，零压比热仍由 REFPROP 的摩尔比热除以其摩尔质量得到。手册没有提供完整 `gas.dta`、精确临界常数和原始样条节点，因此应称为“遵循 Sage 公开公式和拟合系数”，不能宣称逐位复现某一 Sage 版本。

## 3. Sage 的物性插值是什么

PDF 145–146 / 印刷 141–142 页说明 Ideal/RK 的样条数据是 `Cp0(T)`、`mu0(T)`、`k0(T)`，其中 `Cp0` 为零压定压比热；黏度和导热系数只依赖温度。PDF 326 / 印刷 322 页说明使用约束三次样条以减少过冲。本包使用 MATLAB `pchip`，同为保形分段三次插值；不声称与 Sage 样条实现逐点相同。

这些是一维物性曲线，不是 RK 的压力或压缩因子的二维查表。Sage 在代表温度 `T0` 处取 `Cp0(T0)` 定出常数 `gamma` 和 `Cv0`，内能继续使用常 `Cv0`（PDF 146、148、151 / 印刷 142、144、147 页）。本实现有参考表时以 `T0=max(300 K,表的最低温度)` 的 `Cp0-R` 设置 `Cv0`，因此 CO₂ 为 305 K，其余为 300 K；无参考表时使用工质原有常量。`idealCp(T)` 单独返回零压曲线；`state.Cp` 始终表示与 `state.InternalEnergy` 一致的状态导数，不用 `Cp0(T)` 覆盖它。

因此 REFPROP 建表用于补足 `Cp0(T)` 与独立输运曲线，并无需在每次 RK 计算时调用 REFPROP。公开的 Sage 系数已经存在，本次不重新拟合或将其冒称为新的 REFPROP 拟合结果。REFPROP 有限微小压力采样得到的量应如实标注为稀薄近似；只有调用理想气体/零密度接口才标注为严格零压值。

## 4. 气态边界与越界处理

用户目标域为 `10–800 K`、`0.1–20 MPa`。仅在 `gasprop.validation(true)` 时，公开 `state`、`density` 和 `idealCp` 才强制检查温区并报 `gasprop:RKRange`，`state` 与 `density` 同时拒绝压力范围以外的状态，表格插值拒绝外推。校验默认关闭，由调用者保证输入域有效，不保证越界拒绝或外推结果有效。边界的极小相对容差只为容纳密度反演产生的压力舍入误差，不扩展物理适用域。

为保持单一气体/超临界分支，最低温度取用户目标下限、参考数据有效下限、REFPROP 建表给出的固相排除下限、以及 `1.001*max(真实临界温度,RK自身临界温度)` 的最大值。这是保守的矩形工作域：可能排除临界温度以下仍可用的低压蒸汽，以避免求解时进入液相或多根区域。参考数据不足以覆盖固相边界时，不应把该边界描述为已经由 RK 独立识别。

Sage 拟合 `a,b` 会改变该三次 EOS 的数学临界温度：

`TcRK = [ a/(R*b) * 0.08664034996495772/0.4274802335403414 ]^(2/3)`。

H2 的 `TcRK` 约为 35.3 K，高于真实临界温度约 33.1 K，故不能仅以真实临界温度截断。He 的 `TcRK` 约 7.8 K，10 K 高于此值，但高压融化边界仍须由 REFPROP 数据准备阶段核查。

Sage 在 PDF 147 / 印刷 143 页已说明其更推荐 Tabular Gas；PDF 327–328 / 印刷 323–324 页的对照也显示低温高压处 RK 偏差较大。本实现保证公式、分支和物性导数一致，不意味着 RK 在整个工作域具有 REFPROP 的精度。误差对照应由 `validation/` 显式运行，不进入核心求解调用链。
